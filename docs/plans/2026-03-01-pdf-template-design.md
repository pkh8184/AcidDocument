# PDF 템플릿 내보내기 디자인

## 목적
기획서/제안서 용도로 문서를 포트폴리오 수준의 PDF로 내보내기.
현재 문서 데이터는 건드리지 않고, 내보내기 시점에 정해진 템플릿을 적용.

## 접근 방식
CSS @media print 기반 (방식 A). window.open() + window.print() 유지.
커버/목차/본문을 구조화된 HTML로 재구성하고 인쇄 CSS 적용.

## 사용자 흐름
1. 내보내기 모달 → PDF 클릭
2. 템플릿 선택: "기본" (기존) / "기획서" (신규)
3. 선택 후 새 창에서 인쇄

## 기획서 PDF 구조 (A4)

### 1페이지: 커버
- 워크스페이스명 (상단)
- 문서 제목 (중앙, 대형)
- 작성자 + 작성일
- 하단 악센트 라인

### 2페이지: 목차
- "목차" 제목
- h1~h5 기반 자동 생성, 들여쓰기 계층

### 3페이지~: 본문
- 상단 헤더: 문서 제목 (좌측, 작은 글씨)
- 하단 푸터: 페이지 번호 (가운데)
- h1에서 자동 page-break
- 정리된 타이포그래피

## 수정 파일
- export.js: exportPdfTemplate() 함수 추가
- index.html: 내보내기 모달 PDF 항목을 템플릿 선택으로 교체
