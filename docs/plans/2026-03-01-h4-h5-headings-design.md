# H4/H5 제목 확장 디자인

## 목적
h1~h3까지만 지원하던 제목 블록을 h1~h5로 확장하여 문서의 계층 구조를 세분화한다.

## 요구사항
- 슬래시 메뉴(`/`), 상단 툴바, 블록 컨텍스트 메뉴(⋮)에서 h4/h5 삽입/변환 가능
- 목차(TOC 인라인 블록 + 플로팅 네비)에 h4/h5 포함 (l4, l5 들여쓰기)
- `/h` 입력 시 h1~h5 전체 필터링 (기존 필터 로직이 자동 처리)
- 기존 h1~h3 동작에 영향 없음
